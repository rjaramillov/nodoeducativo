Paso 1 de 10 · Concepto fundamental

¿Qué es CSS y qué cambia en una página?

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Su función es controlar la presentación visual del contenido estructurado con HTML.

Al terminar este paso debes poder explicar: “HTML estructura el contenido y CSS controla cómo se presenta”.

Referencia del concepto: MDN describe CSS como el código que da estilo al contenido web y enseña CSS después de una base de HTML.

Importante: CSS no cambia que un <h1> sea un título ni que una lista siga siendo una lista. Cambia su apariencia.

Paso 3 de 10 · Organización

¿Dónde escribimos el CSS?

CSS puede escribirse de varias formas. Para este proyecto usaremos una hoja externa porque separa estructura y presentación.

Práctica del curso: index.html contiene la estructura y styles.css contiene los estilos.

En línea

<h1 style="color:navy">Ana</h1>

Útil para casos muy puntuales, pero mezcla contenido y presentación. No será nuestra estrategia principal.

Interno

<style>
h1 { color: navy; }
</style>

Funciona para demos o documentos pequeños, pero los estilos quedan dentro del HTML.

Externo

<link rel="stylesheet"
 href="styles.css">
✓ Recomendado para este proyecto

Separa responsabilidades y facilita reutilizar, mantener y organizar los estilos.

Paso 4 de 10 · Elegir qué estilizar

El selector es la “puntería” de CSS

Selecciona un tipo de selector y observa exactamente qué parte del CV recibe el estilo.

Idea central: antes de escribir una propiedad, debes decidir qué elementos quieres modificar.
h1 selecciona todos los elementos <h1>. En este CV solo hay uno: el nombre principal.

Cascada y especificidad: solo lo indispensable por ahora

Si varias reglas intentan cambiar la misma propiedad del mismo elemento, CSS decide cuál aplicar. Para comenzar: un ID suele ser más específico que una clase y una clase más específica que un selector de elemento; si la especificidad empata, normalmente gana la regla que aparece después. Evita usar !important como solución habitual.

Paso 6 de 10 · Tipografía + modelo de caja

CSS también controla cuánto “respira” el contenido

La tipografía modifica cómo se lee; el modelo de caja explica el espacio que ocupa cada elemento.

Debes visualizar: contenido → padding → border → margin.

Es una práctica común porque hace más predecible el tamaño de las cajas: el ancho declarado incluye padding y borde. Por eso verás con frecuencia * { box-sizing: border-box; } al inicio de una hoja de estilos.

Paso 7 de 10 · Distribución y adaptación

Un diseño debe organizarse y adaptarse, no solo “verse bonito”

Usaremos un layout sencillo con Flexbox y una media query para que el CV funcione en escritorio y móvil.

Debes reconocer: display:flex, gap, max-width y @media.

Regla clave

.cv-layout {
  display: flex;
  gap: 2rem;
}

@media (max-width: 700px) {
  .cv-layout {
    flex-direction: column;
  }
}
Cambia el tamaño del dispositivo
Vista de escritorio

Paso 8 de 10 · Convenciones

CSS mantenible: no es solo que funcione, sino que se entienda

Antes de diseñar el CV final, revisa decisiones que harán tu CSS más claro y predecible.

Objetivo: escribir estilos que otra persona pueda leer, modificar y reutilizar.

Piensa en styles.css como un archivo con zonas

No se trata de poner reglas donde “quepan”. Una hoja mantenible permite localizar rápido qué controla cada bloque y modificarlo sin romper lo demás.

Difícil de entender

orden + nombres claros + reutilización = CSS mantenible

Si otra persona puede encontrar, entender y cambiar una regla, vas por buen camino.

Ahora mira el mapa convertido en código

Los colores del código tienen un significado constante: selector, propiedad, valor, variable, comentario y regla especial.

selectorpropiedadvalorvariablecomentario@regla 
/* 1. Variables: valores que reutilizarás */
:root {
  --color-principal: #176a9b;
  --espacio: 1rem;
}

/* 2. Base: reglas generales */
* {
  box-sizing: border-box;
}
body {
  color: #17324d;
  line-height: 1.6;
}

/* 3. Componentes: zonas del CV */
.cv-header {
  background-color: var(--color-principal);
}
.cv-section {
  padding: var(--espacio);
}

/* 4. Estados: interacción */
a:hover,
a:focus-visible {
  text-decoration-thickness: 3px;
}

/* 5. Responsive: adaptación */
@media (max-width: 700px) {
  .cv-layout {
    flex-direction: column;
  }
}
