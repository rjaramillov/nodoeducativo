¿Qué es HTML y para qué sirve?

Antes de aprender etiquetas, necesitas saber exactamente qué problema resuelve HTML.

Al terminar este paso debes poder explicar: “HTML sirve para dar estructura y significado al contenido de una página web”.
Antes de empezar · diagnóstico personal (no califica)

¿Qué tan seguro te sientes ahora para explicar qué es HTML y construir una página sencilla?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es un lenguaje de marcado que indica al navegador cómo estructurar el contenido de una página web.
Referencia del concepto: MDN explica que HTML es un lenguaje de marcado que indica a los navegadores cómo estructurar las páginas web (Mozilla Developer Network, 2026).

HyperText

“Hipertexto”: contenido que puede conectarse con otros recursos mediante enlaces.

Markup

“Marcado”: etiquetas que identifican qué representa cada parte del contenido.

Language

“Lenguaje”: una sintaxis y reglas que el navegador sabe interpretar.

Importante:HTML no se estudia aquí como un lenguaje de programación. Su función inicial es marcar y organizar contenido: qué es un título, un párrafo, una lista, un enlace, una imagen, etc.

Una forma sencilla de pensarlo

Imagina que tienes información escrita, pero nadie sabe qué parte es el título, qué parte es una lista o qué parte es un enlace. HTML etiqueta cada pieza para que el navegador sepa qué representa.

Paso 2 de 8 · La unidad básica

Una etiqueta le dice al navegador qué es cada contenido

Aprender HTML empieza por entender un elemento completo, no por memorizar decenas de nombres.

Al terminar: distinguirás etiqueta de apertura, contenido, etiqueta de cierre y atributo.

Explora este elemento

Haz clic en cada parte. Después prueba el ejemplo con un enlace, que incluye un atributo.

Referencia técnica: MDN define un elemento como la etiqueta de apertura, su contenido y la etiqueta de cierre; los atributos agregan información adicional al elemento (MDN, 2026).
<p> · etiqueta de apertura

Marca dónde comienza el elemento

La letra p significa “paragraph” (párrafo). El navegador entiende que el texto que sigue forma un párrafo.

Paso 3 de 8 · La estructura mínima

Ahora arma el “contenedor” de una página completa

Los elementos no viven aislados. Un documento HTML tiene una estructura base que el navegador interpreta.

Al terminar: sabrás para qué sirven <html>, <head>, <title> y <body>.

Haz clic en una línea

HEAD · información para el navegadorConfiguración, título de pestaña, metadatos. Normalmente no aparece como contenido de la página.
BODY · contenido que ve la personaTítulos, párrafos, listas, enlaces, imágenes, formularios, etc.

Paso 5 de 8 · Organizar la página
Una página también se divide en regiones con significado
Cuando el contenido crece, necesitas organizarlo en zonas. Para una primera página, empieza por pocas regiones claras.
Al terminar: reconocerás <header>, <main>, <section> y <footer>; usarás <nav> cuando haya navegación.








headerNombre y presentación del CV
navPerfil · Habilidades · Contacto
mainContenido principal
sectionHabilidades
sectionEducación
footerContacto y cierre
<header> introduce la página o una sección. En un CV puede contener tu nombre y perfil.




Regla para no complicarte
No uses una etiqueta porque “se ve bonita”. Úsala por lo que significa. W3C recomienda marcar la estructura con elementos semánticos apropiados, de modo que las relaciones sean comprensibles para navegadores y tecnologías de asistencia.
¿Y <article> / <aside>?
Existen y son importantes, pero no necesitas dominarlos para tu primera página. Primero consolida la estructura básica. Después podrás aprender que <article> representa contenido autocontenido y <aside> contenido complementario.

Marca el significado del contenido para que el navegador pueda interpretarlo.


2 · Los elementos tienen partes
Etiqueta de apertura + contenido + cierre; algunos incluyen atributos.


3 · Existe una estructura base
html, head y body organizan el documento.


4 · Elige por significado
Título, párrafo, lista, enlace e imagen responden a intenciones diferentes.
